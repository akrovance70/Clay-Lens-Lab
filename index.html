⚖️ Scoring Methodology & Optical Transparency

Heuristic Clarification: Ratings displayed in this application are mathematical screening heuristics derived from published VLT percentages and dealer environmental descriptions. They are not certified performance ratings from Pilla Sport or Carl Zeiss Vision. A rating of 5/5 indicates that a lens meets standard optical heuristics for that specific condition, not that it is universally superior. Eye color alone does not determine lens suitability.
☀ Direct Sunshine (1–5):

Based strictly on Visible Light Transmission (VLT). Darker lenses block more total solar radiation: VLT ≤ 25% scores 5; ≤ 40% scores 4; ≤ 55% scores 3; ≤ 70% scores 2; > 70% scores 1.

☁ Overcast Skies (1–5):

Higher transmission lenses and formulations documented for flat, diminishing, or low light score higher (up to 5/5 for VLT ≥ 50% with low-light documentation).

🌾 Dormant Brown Backgrounds (1–5):

Lenses documented for open field or desert environments featuring warm contrast profiles (orange, amber, red, brown) receive higher screening scores. This heuristic is the least validated and has not been tested via controlled optical target-contrast benches.

Methodology, Sources & Data Integrity

1. Authoritative Data Provenance

Clay Lens Lab indexes 43 Pilla Outlaw shooting-glasses lenses derived from authorized dealer technical filtration guides and official Pilla Sport publications. Every record includes audit fields:

  • Source Type: Distinguishes authorized dealer filtration guides from official catalog literature.
  • Disputed Classification Notice: Lens 80CMOS is preserved as HC* because distributor documentation contains conflicting classifications (CMOS traditionally indicates Chromashift Max Orange, while dealer indices classified it under High Contrast).

2. Heuristic Scoring Formulas

Individual ratings (1 to 5) are generated by deterministic rules:

// Direct Sunshine (VLT heuristic) vlt <= 25 ? 5 : vlt <= 40 ? 4 : vlt <= 55 ? 3 : vlt <= 70 ? 2 : 1; // Overcast Skies (VLT & Lighting descriptor heuristic) if (light.includes('flat') || light.includes('low')) return vlt >= 50 ? 5 : 3; vlt <= 20 ? 1 : vlt <= 35 ? 2 : vlt <= 50 ? 3 : vlt <= 70 ? 4 : 5; // Dormant Brown Backgrounds (Environment & Color heuristic) if (env.includes('open field') || env.includes('desert')) { return /orange|amber|red|brown/.test(color) ? 5 : 4; } return 2;

3. Personalized Composite Scoring Formula

The personalized score combines the three base ratings using your normalized custom weights:

Composite Score = (W_sun × Sun + W_cloud × Cloud + W_brown × Brown) / (W_sun + W_cloud + W_brown)

If all weights are zero, the composite score evaluates cleanly to 0.00 without division-by-zero errors.

Optical Reality Check: No algorithm can replace trying a lens at your local shooting ground. Lighting conditions, clay target color (fluorescent orange, lime green, black, white), ocular physiology, and personal contrast sensitivity all influence on-target visibility.
